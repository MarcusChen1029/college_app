# Paid Plans with ECPay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the free-to-pick Free / Junior / Senior plans with Free (5 colleges) and a NT$990 admission-year pass sold through ECPay, where only the server can grant the pass.

**Architecture:** A Supabase Edge Function `payments` creates ECPay orders and receives ECPay's signed notices; it writes through service-role-only SQL functions. Pure logic (pass dates, ECPay signing, notice handling) lives in dependency-free `supabase/functions/_shared/*.ts` files that the web test runner imports. The web app reads the server-written `plan_windows` and computes the effective plan for "today in Taipei"; a trigger silently ignores any plan value a client sends.

**Tech Stack:** Next.js 16 (App Router), React 19, Tailwind 4, supabase-js 2.118, Supabase Postgres + Deno Edge Functions, `node --test` with type stripping.

**Spec:** `docs/superpowers/specs/2026-10-29-payments-design.md` (read it first; this plan argues from it).
